# CLAUDE.md — project context for AI assistants

Read this first. It's the orientation primer for any session that
touches this repo.

## What this is

PCA / factor research on a rate-and-vol cube indexed by
`(expiry, tenor)`. End goal: decompose daily cube moves into a few
interpretable factors that can be used as hedging reference.

## Terminology — strict

* **`expiry`** — forward-starting time of the option / forward
  (1M, 2M, 3M, 6M, 9M, 1Y, 2Y, 3Y, 4Y, 5Y, 7Y, 10Y, 12Y, 15Y, 20Y, 25Y, 30Y).
* **`tenor`** — length of the underlying rate
  (1Y, 2Y, 3Y, 4Y, 5Y, 7Y, 10Y, 12Y, 15Y, 20Y, 25Y, 30Y).
* **Do not use `maturity`** anywhere. `pca.load_long` accepts pkls that
  use the legacy `maturity` column name and renames it for back-compat,
  but new code / data should be `tenor`.

## Environment split

* **Local** (this repo): mock data only, four pkls in `data/mock/`
  generated by `mock_data.py`. Used for methodology development.
* **Company**: a separate script (not in this repo, not Claude's job
  to write) pulls real data via internal API and emits pkls in the
  identical long-format `[date, expiry, tenor, value]` shape. The
  analysis code in this repo is unchanged across environments — just
  swap the pkls.

## Code conventions

* **Stay flat and minimal.** No `src/` package, no class hierarchies,
  no schema modules. Helpers are single files at the project root
  (`pca.py`, `mock_data.py`). The notebook is allowed to do real work
  inline.
* **No Bloomberg loader.** Removed deliberately. Don't bring it back.
* **No HMM / regime detection / scenario classifier.** Removed in the
  simplification pass. `mock_data.py` still emits `true_regimes.pkl`
  as a colouring aid for plots, but no model consumes it.
* **No tests, no CI.** Removed in the simplification pass.
* **Helper extensions are OK** but should stay tight — one function,
  pure inputs/outputs, no state. If something needs a class, push
  back first.

## File map

* `mock_data.py` — synthetic generator. Regime-switching DGP (3-state
  Markov chain → OU level + slope + vol). Full `expiry × tenor`
  cross-product (no length filter). Run as a script to regenerate
  `data/mock/`.
* `pca.py` — `load_long(path)`, `to_wide(long_df)`, `run_pca(wide, k)`,
  `reconstruct(scores, loadings, wide, k)`. Plus `EXPIRY_LABELS` /
  `TENOR_LABELS` constants. `load_long` filters to these canonical
  sets, regardless of what the pkl contains.
* `notebooks/pca.ipynb` — current research notebook. 9 sections covering
  rate PCA, vol PCA, loading heatmaps, regime-overlay score series,
  cross-surface correlation, reconstruction quality, stability.
* `data/mock/{rate, atm_vol, skew_p2, skew_n2}.pkl` — long-format
  DataFrames with columns `[date, expiry, tenor, value]`. 500 days ×
  204 pairs = 102,000 rows each.
* `data/mock/true_regimes.pkl` — ground-truth latent regime path
  (integer 0/1/2 series indexed by date).

## Active research direction

The vanilla PCA in `notebooks/pca.ipynb` is the baseline. Priority
extensions (in order):

1. **Varimax-rotated PCA** — rotate vanilla PCA loadings to maximise
   loading sparsity per factor. Same cumulative variance.
2. **Hierarchical PCA** — extract cube mean (level), run PCA on the
   residual. Decouples PC1 from level-dominance.
3. **Pre-defined bucket factors + residual PCA** — hand-defined
   economic regions regressed out, then residual PCA. Most directly
   hedge-mappable.
4. **Joint rate-vol cross-surface structure** — CCA or lagged
   correlation between rate factors and vol factors.

**Comparison metrics** for each: variance retained at K factors,
loading sparsity, factor stability under rolling refit, hedge
replication residual.

## Out of scope

* Parametric overlays (Nelson-Siegel, SABR, SVI) — possibly Phase 2,
  not now.
* Tensor decomposition (Tucker / CP).
* Autoencoders / nonlinear factor models.
* Regime detection (HMM was here and got deleted).
* Real Bloomberg data ingestion.
* Production deployment / scheduled refits.

## When in doubt

* Prefer one extra inline cell in the notebook over a new helper file.
* Prefer one extra parameter on an existing function over a new function.
* Ask before adding any dependency. Current set: pandas, numpy,
  scikit-learn, matplotlib, seaborn, jupyter.
